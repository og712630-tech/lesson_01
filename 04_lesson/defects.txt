БАГ-РЕПОРТ №1
================================================================================
Краткое описание: Неверное поведение метода contains при передаче пустой строки
                  в качестве искомого символа.

Шаги воспроизведения:
1. Создать экземпляр класса StringUtils.
2. Вызвать метод contains с параметрами: string="abc", symbol="".
3. Проверить возвращаемое значение.

Ожидаемый результат: False (пустая строка не может содержаться в строке).

Фактический результат: True (метод возвращает True).

Причина: Метод contains использует string.index(symbol), который для пустой
        подстроки всегда возвращает 0, что считается как > -1, и метод
        возвращает True.

Серьёзность: Незначительная (Minor).
Приоритет: Низкий (Low).
Компонент: StringUtils.contains.

================================================================================
БАГ-РЕПОРТ №2
================================================================================
Краткое описание: Метод trim удаляет только пробелы в начале, но не удаляет
                  табуляцию или другие пробельные символы.

Шаги воспроизведения:
1. Создать экземпляр класса StringUtils.
2. Вызвать метод trim с параметром string="\tskypro" (табуляция в начале).
3. Проверить возвращаемое значение.

Ожидаемый результат: "skypro" (табуляция должна быть удалена).

Фактический результат: "\tskypro" (табуляция остаётся).

Причина: Метод trim удаляет только символ пробела (" "), но не обрабатывает
        другие пробельные символы (табуляция, перевод строки и т.д.).

Серьёзность: Средняя (Major).
Приоритет: Средний (Medium).
Компонент: StringUtils.trim.

БАГ-РЕПОРТ №3
================================================================================
Краткое описание: Метод delete_symbol не удаляет символ, если содержит пробелы
                  в начале строки (из-за особенности trim?).

Шаги воспроизведения:
1. Создать экземпляр класса StringUtils.
2. Вызвать метод delete_symbol с параметрами:
   string="   SkyPro", symbol="S".
3. Проверить возвращаемое значение.

Ожидаемый результат: "   kyPro" (пробелы сохраняются, буква S удаляется).

Фактический результат: "   SkyPro" (буква S не удаляется).

Причина: Метод contains внутри delete_symbol ищет символ "S" в строке "   SkyPro",
        но из-за пробелов в начале метод содержит его не находит? (Требуется
        дополнительное расследование: возможно, ошибка в contains при работе
        с пробелами или в логике delete_symbol).

Серьёзность: Средняя (Major).
Приоритет: Высокий (High).
Компонент: StringUtils.delete_symbol (связан с contains).
